# optes
OPTES - Ontologia do Portal da Transparência do ES


├─ docs/ : Diretório separado para arquivos do github pages que formaliza a ontologia e para o GitHub pages
├─ documentacaoOntologia/ : Diretório separado para documentos que formalizam a ontologia e a metodologia de construção da ontologia.
│   ├── documentacaoOntologia/sabiox : Subdiretório separado para documentos do sabiox
│   ├── documentacaoOntologia/metodo : Subdiretório separado para documentos que descrevem a metodologia de construção da ontologia, assim como instruções de reuso dos artefatos produzidos.
├─ tonto/ : Diretório separado para ontologia de referencia em Tonto
├─ ontologiaDados/ : Diretório separado para conter os arquivos com os dados transformados
├─ README.md : Explicação geral do repositório, com explicações de cada diretório/subdiretório e como reusar o repositório
