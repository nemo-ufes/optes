# optes
OPTES - Ontologia do Portal da Transparência do ES


├─ docs/ : Diretório separado para documentação que formaliza a ontologia e para o GitHub pages
│   ├── docs/sabiox : Subdiretório separado para documentos do sabiox
│   ├── docs/metodo : Subdiretório separado para documentos que descrevem a metodologia de construção da ontologia, assim como instruções de reuso dos artefatos produzidos. (Facilitar o pessoal da SECONT validar os resultados, deixando o projeto mais reprodutível)
│   ├── docs/githubPages : Subdiretório separado para documentos do GitHub pages
├─ ontologia/ : Diretório separado para ontologia de referencia e operacional
│   ├── ontologia/tonto: Subdiretório separado para arquivos tonto e imagens da ontologia em tonto
│   ├── ontologia/ttl: Subdiretório separado para arquivos .ttl gerados a partir dos arquivos tonto
├─ ontologiaDados/ : Diretório separado para conter os arquivos com os dados transformados
├─ README.md : Explicação geral do repositório, com explicações de cada diretório/subdiretório e como reusar o repositório
